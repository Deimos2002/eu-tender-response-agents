# TECHNICAL SPECIFICATIONS
**Real-time Graphics Controller**
Buyer : Yleisradio Oy  
Notice reference : TED 452622-2026

## 1. Subject of the contract
The object of the procurement is Real-time Graphics Controller for Yleisradio Oy ("Yle"). Yle is looking for a supplier for a graphics controller. The solution should be ready-made and already in production use. The controller will play a crucial role in Yle’s real-time graphics production. The goal is to have one UI to unify workflow between different graphic renderer systems. Yle’s production environment consists of 12 tv studios, 3 OB trucks, 1 playout centre and roughly dozen cloud live streaming units. Content filling clients have around 1300 installations. Concurrent users are around 100. The scope of initial installation is to install controller setup to one local studio in Pasila, Helsinki. This studio is using SPX html graphics, Caspar CG and Unreal as graphic renderers. After a successful production transition Yle is looking for expand this controller solution as a company wide solution. Evaluation of Tenders Yle will choose one (1) supplier as a contracting party as a result of this bidding competition. The Agreement includes two extension options described in the tender documents.
